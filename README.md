A responsive personal portfolio website showcasing my skills, projects, experience, and professional profiles through a clean and modern interface.

🌐 Live Demo

Live Website:
https://bridget-pais.github.io/bridget-portfolio/

✨ Features

- Responsive personal portfolio design
- Personal introduction and profile section
- Skills section with category-based filtering
- Project showcase with project cards
- Project links
- GitHub and LinkedIn profile links
- Smooth animations and interactive elements
- Mobile-friendly navigation
- Clean and modern user interface

🛠️ Technologies Used

- HTML5 — Website structure and semantic markup
- CSS3 — Styling, animations, layouts, and responsive design
- JavaScript — Interactivity, filtering, navigation, and dynamic behavior

Clone the Repository

Open the Project

Open "index.html" in a browser, or use Live Server in Visual Studio Code for local development.
